# Գաղտնաբառի վերականգնում՝ 6-նիշանոց կոդով

Ընթացքը՝ էլփոստ → կոդի հարցում → 6 թվանշանի մուտքագրում → նոր գաղտնաբառի կրկնակի մուտքագրում։ Կոդը չի դրվում հասցեի տողում։ Էլփոստի հաստատման նախկին հղումները շարունակում են աշխատել։

Demo-ի MAIL_BACKEND=local ռեժիմում իրական նամակ չի ուղարկվում։ Կոդը ստացվում է `python -X utf8 -m tools.local_mailbox --email ՀԱՍՑԵ --latest` հրամանով՝ code դաշտից։ purpose-ը reset-code է։ Այդ ելքը և կոդը պետք չէ հրապարակել։ Իրական նամակների համար անհրաժեշտ է առանձին SMTP կարգավորում։

Կոդը 6 պատահական թվանշան է, գործում է 10 րոպե։ Բազայում պահվում է միայն աղով PBKDF2-SHA256 ամփոփումը՝ 600000 քայլով, առկա PasswordResets.Code դաշտում։ Կոդի նոր հարցումը չեղարկում է նախորդ reset հղումները/կոդերը։ Հաստատումից հետո կոդը փոխարինվում է գաղտնի, 5 րոպե գործող reset token-ով։ Գաղտնաբառի հաջող փոփոխությունն անվավեր է դարձնում մյուս reset-ները և հին սեսիաները։

Հարցումները սահմանափակված են էլփոստով և IP-ով։ Կոդի ստուգումը թույլ է տալիս մինչև 5 փորձ 15 րոպեանոց պատուհանում՝ էլփոստի համար։ Անհայտ, չհաստատված կամ ոչ ակտիվ հաշվին կոդ չի ստեղծվում, բայց հարցման պատասխանը չի բացահայտում հաշվի գոյությունը։ Դերի և հաշվի կապը ստուգվում է։ Նոր SQL կառուցվածք չի պահանջվում, եթե 03 հաշիվների թարմացումն արդեն կիրառված է։

Ստուգված են մեկուսացված SQLite-ով՝ իրական ծառայությունների և մուտքի գործառույթի միջոցով, կոդի ժամկետը, մեկանգամյա օգտագործումը, սխալ հաշիվը/դերը, կրկնակի հարցումը, փորձերի սահմանափակումը, նոր/հին գաղտնաբառերը և սեսիաների չեղարկումը։ DOM փորձնական միջավայրում ստուգված են էջի բոլոր քայլերը և էլփոստի հաստատման հին հղումը։ Իրական MSSQL/browser վերջնական ընդունումը դեռ պետք է կատարել տեղային համակարգչում։
