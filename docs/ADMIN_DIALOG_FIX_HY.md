# Ադմինի պատուհանների և լեզվի ուղղում

Նոր account-dialog ոճավորումը առանձին accounts-ui.css-ում է։ Վերնագիրն ու փակման × կոճակը մնում են ոլորվող բովանդակությունից դուրս։ Փակվում է նաև Escape-ով, իսկ փակված dialog-ը հեռացվում է էջից։ Հին admin-styles.css-ը չի փոխվել։

Թույլատրված ցանկի լռելյայն ֆիլտրը ցույց է տալիս դեռ չգրանցվածներին. «Բոլորը» տարբերակով երևում են նաև գրանցվածները։ Օգտատերերի հիմնական ցանկը մնում է ստեղծված հաշիվների համար։

Անգլերեն էջերի տվյալները ստանում են DisplayName դաշտ. անունները տառադարձվում են սերվերում, իսկ FirstName/LastName բնօրինակները պահպանվում են և օգտագործվում խմբագրման ժամանակ։ Մեկնաբանությունները չեն թարգմանվում։ Ադմինի անգլերեն էջերի Student website հղումը նույնպես ուղղված է։ Գրանցման վերնագիրը և կոճակը միատեսակ Sign up / Գրանցվել են, բացատրությունը կրճատված է։

Անցել են ASGI/SQLite ստուգումները՝ գրանցման ամբողջ շղթա, իրավունքներ, DisplayName-ի և բնօրինակների պահպանում, դեռ չգրանցվածների ֆիլտր։ DOM միջավայրում ստուգված են ցուցադրվող անունները, պատուհանի վերնագրի փակման կոճակն ու փակվելիս հեռացումը։ Իրական բրաուզերում վերջնական տեսքի ստուգումը մնում է տեղային փուլին։ SQL կառուցվածքի փոփոխություն պետք չէ։
