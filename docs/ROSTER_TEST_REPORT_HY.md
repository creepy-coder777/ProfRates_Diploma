# Գրանցման նոր ընթացքի ստուգում

Մեկուսացված SQLite բազայով ստուգվել են իրական FastAPI ASGI երթուղիները՝ առանց authentication-ը փոխարինող dependency override-ի։ Փոխարինվել է միայն տվյալների բազայի կապը՝ հիշողության SQLite-ով։ Windows sandbox-ի IOCP wakeup-ը շտկվել է միայն փորձարկման գործարկիչում։

Անցել են՝ անանուն և ուսանողական մուտքի արգելքը ադմինի ցանկի API-ին, ադմինի թույլտվությամբ գրառում ավելացնելը, կրկնվող և պասիվ խմբի մերժումը, անհայտ հասցեի մերժումը, կեղծ անուն/խմբի դաշտերի մերժումը, գրանցման տվյալների վերցնումը ցանկից, էլփոստի հաստատման պարտադիր լինելը, մուտքը և գնահատելու ավտոմատ կապերը, կրկնակի գրանցման մերժումը, ցանկից ապաակտիվացնելուց հետո սեսիայի անվավեր լինելը, հին հաշվի շարունակվող աշխատանքը։

DOM փորձնական միջավայրում ստուգվել են նոր գրանցման պահանջները և ընդհանուր մուտքի կոդի համատեղելիությունը։ Python և երկու փոփոխված JavaScript ֆայլերի շարահյուսական ստուգումն անցել է։ Նախկին account/UI թեստերը հարմարեցվել են նոր պայմանագրին, ավելացվել են ցանկի թեստեր, բայց ամբողջ pytest փաթեթը այս փուլում չի գործարկվել։

Չեն հաստատվել՝ 04_student_roster.sql-ի գործարկումն իրական MSSQL-ում, ադմինի նոր երկխոսությունների վերջնական browser տեսքը և բուհի պաշտոնական ցանկի իսկությունը։ Կոդը չի փոխարինում հին հաշիվների աղբյուրի տվյալների ճշտմանը։
